Lion Agent 최초 연결 설정

GitHub Pages는 SSH를 직접 실행할 수 없습니다. Windows의 로컬 Agent가 SSH 키로 Lion 상태를 읽고, 브라우저에는 JSON 상태만 전달합니다.

전체 연결 구조

GitHub Pages 화면
    ↓  Bearer token + CORS
http://127.0.0.1:8765  (내 Windows의 Lion Agent)
    ↓  SSH key / BatchMode=yes
lion.jbnu.ac.kr
    ↓  내부 ssh
lion28, lion29, ..., tlion3
비밀번호와 SSH 개인키는 웹페이지나 GitHub 저장소에 넣지 않습니다. 브라우저에는 Agent 접근 토큰만 현재 탭의 sessionStorage에 보관됩니다.

1. Windows SSH 키 준비

PowerShell에서 다음 명령을 실행합니다. 이미 사용할 SSH 키가 있다면 새로 만들 필요가 없습니다.

ssh-keygen -t ed25519 -C "ys-empire-lion"

기본 경로인 C:\Users\사용자명\.ssh\id_ed25519를 사용합니다. 개인키에 암호를 설정했다면 Windows ssh-agent에 한 번 등록합니다.

Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add $env:USERPROFILE\.ssh\id_ed25519
서비스 설정 명령에서 권한 오류가 나면 PowerShell을 관리자 권한으로 한 번 실행합니다.

2. 공개키를 JBNU 게이트웨이에 등록

아래 명령은 공개키만 게이트웨이의 ~/.ssh/authorized_keys에 추가합니다. 이 단계에서는 기존 Lion 비밀번호를 한 번 입력할 수 있습니다.

Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | ssh skylark@lion.jbnu.ac.kr "umask 077; mkdir -p ~/.ssh; cat >> ~/.ssh/authorized_keys; chmod 700 ~/.ssh; chmod 600 ~/.ssh/authorized_keys"

접속 테스트

ssh -o BatchMode=yes skylark@lion.jbnu.ac.kr "hostname"
ssh skylark@lion.jbnu.ac.kr "ssh -o BatchMode=yes lion28 hostname"
두 명령 모두 비밀번호 입력 없이 호스트명이 출력되면 자동 로그인 준비가 끝난 것입니다.
연구실 정책상 공개키 등록이 금지되거나 2단계 인증이 강제되는 경우에는 자동 SSH 수집이 불가능할 수 있습니다. 이 경우 관리자의 허용이 필요합니다.

3. Lion Agent 설정과 실행

  1. 저장소를 내려받거나 동기화합니다.
  2. server-agent\run_agent.bat을 실행합니다.
  3. 처음 실행하면 config.example.json이 config.json으로 복사됩니다.
  4. api_token을 충분히 긴 임의 문자열로 바꿉니다.
  5. 배치 파일을 다시 실행합니다.

PowerShell에서 안전한 토큰을 생성하는 예:

[Convert]::ToHexString((1..32 | ForEach-Object { Get-Random -Maximum 256 }))

Agent가 정상 실행되면 다음 주소가 열립니다.

http://127.0.0.1:8765/api/health
config.json, SSH 개인키, server-agent/data/는 GitHub에 업로드하지 않습니다.

4. 영섭랜드 화면에서 연결

  1. 영섭랜드 하단의 샘플 데이터 / Lion Agent 미연결 버튼을 누릅니다.
  2. Agent 주소는 http://127.0.0.1:8765로 둡니다.
  3. config.json의 api_token을 입력합니다.
  4. 연결 테스트 후 저장하고 연결을 누릅니다.

연결 후에는 10초 간격으로 상태가 갱신되며, 새로고침 버튼은 Agent에 즉시 재수집을 요청합니다.

문제: HTTP 401

화면에 입력한 토큰과 server-agent/config.json의 api_token이 다릅니다.

문제: 연결 시간 초과

Agent가 꺼져 있거나 Windows 방화벽, SSH 접속, 게이트웨이 연결을 확인해야 합니다.

문제: 모든 노드 오프라인

BatchMode=yes 테스트가 비밀번호 없이 성공하는지 먼저 확인합니다.

문제: CORS 오류

allowed_origins에 https://skylark51.github.io가 포함되어 있는지 확인합니다.
